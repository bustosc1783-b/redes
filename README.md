**Regla de autoría:** Theri construyó la topología de Cisco. La documentación de Nico es apoyo y debe cotejarse con el archivo real. Los informes V3 son una elaboración nueva y no modifican las fuentes.

**Estado:** proyecto en desarrollo; faltan configuraciones y pruebas de ping, servicios, VPN y conectividad. No marcar como terminado algo que no esté probado.

**Presupuesto:** la pauta original menciona $20–30 millones; Christopher informó que el profesor autorizó hasta **$35 millones CLP con IVA**. Conservar constancia de la autorización y aportar dos cotizaciones chilenas por ítem relevante.

**Seguridad:** no se vuelven a publicar archivos de configuración completos con claves académicas en este repositorio público. Para acceder a las fuentes originales existentes, usar los enlaces de las carpetas de referencia.
