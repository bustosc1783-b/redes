# Proyecto de Redes Corporativas — Trabajo grupal

Repositorio compartible del proyecto académico de **Casa Matriz y Sucursal Seguras** (Proyecto 2, Cisco Packet Tracer).

## Material separado por autoría y propósito

- **Theri / Cisco:** topología y archivos de Packet Tracer. Su implementación es la fuente técnica principal.
- **Nico / documentación:** textos y configuraciones auxiliares; deben contrastarse con el proyecto de Theri.
- **Revisión de rúbrica V3:** auditoría del avance y pruebas pendientes.
- **Informe técnico V3:** memoria, propuesta al cliente y base de presupuesto.

Los archivos originales no se sobrescriben. Las versiones de avance no equivalen a una red validada por pruebas de conectividad.

**Rúbrica:** 2 sedes, 2 ISP, VPN IPsec, NAT/PAT, DMZ, 6 departamentos/VLAN/SSID por sede, OSPF, DHCP, VoIP/IoT, seguridad, informe PDF, presupuesto y defensa de 15 minutos. El profesor autorizó al grupo hasta **$35 millones CLP** según información entregada por Christopher (pauta original: hasta $30 millones).
